# Land outline

`land-110m.geojson` is Natural Earth's public-domain 1:110m land geometry,
downloaded on 2026-10-25 from the Natural Earth vector repository:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

It is served locally so the aircraft globe does not depend on a third-party
map request at runtime. It provides geographic context, not official aviation
boundaries or flight corridors.
